Gem planning demonstration

Each viewer renders the exact collision geometry. Recording choices compare native execution with five-step (320 ms) predictions made from one synchronized initial state and the recorded bridge commands. Predictions receive no future physical state or camera observations.

These are short control-window replays from live gem pilots, including confirmed pickups. They do not demonstrate reliable multi-second landings or improved trained-policy performance. Committed comparisons restore the same settled spawn/world before each branch; no restore occurs during branch execution. The comparator is a simple routed controller.

Use Recording, Focus trajectory, the Time slider and Largest error. Prior native mechanics/uncertainty recordings remain in the original ten-map viewer.
